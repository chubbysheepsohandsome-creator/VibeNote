# VibeNote · 灵感签

纯文本一键生成高颜值分享卡片。

- 5 套皮肤：留白 / 手账 / 暗夜 / 弥散 / 报刊
- 强调色、字体、字号、留白、尺寸比例（3:4 / 1:1 / 9:16 / 自适应）
- 简单语法：`# 小标题` `**加粗**` `==高亮==` `*斜体*` `- 列表` `1. 编号` `> 引用` `---`
- 导出 2× / 3× 高清 PNG，或直接复制图片；手机上长按保存到相册
- 灵感库：收藏常用卡片，一键恢复文案和样式
- 创作者档案：保存你的署名（不需要密码）
- 所有内容只在浏览器本地处理和保存，不上传任何服务器
- 单个 HTML 文件，不依赖 CDN；网络字体加载不到时自动使用系统中文字体

直接用浏览器打开 `index.html` 即可使用。
